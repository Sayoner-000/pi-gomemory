## Hallazgos de un solo revisor

`SUSPECT` es la categoría del motor por falta de **segunda identificación independiente**, no por ausencia de reproducción. Los cuatro comportamientos se observaron en el binario compilado.

| ID | Evidencia y efecto | Corrección propuesta y comprobación |
|---|---|---|
| C-004 · Media · A-04 | [`uninstall.go:502`](../../pkg/installer/uninstall.go#L502). Con una apertura huérfana anterior al bloque gestionado, `install` salió 0 y eliminó texto propio entre ambos. El parser ya existía en uninstall; ahora lo usa también la migración de install/update. | No retirar rangos ambiguos. Probar apertura huérfana, marcadores duplicados y texto propio entre bloques. |
| C-006 · Media · A-06 | [`uninstall.go:661`](../../pkg/installer/uninstall.go#L661). Con `codemode.json` ilegible como JSON, `uninstall` salió 0, borró el archivo y dejó `+codemode`. | Avisar y conservar el estado inválido para diagnóstico y reintento. Probar JSON truncado y error de lectura. |
| C-007 · Media · B-03 | [`codemode.go:48`](../../pkg/installer/codemode.go#L48), [`uninstall.go:661`](../../pkg/installer/uninstall.go#L661). El booleano de propiedad no identifica el archivo editado. Tras cambiar el destino del enlace de settings, `uninstall` retiró un `+codemode` que ya pertenecía al usuario en el otro destino. | Asociar propiedad al recurso editado y verificarlo al aplicar; preservar si no hay correspondencia. Probar cambio de enlace antes y después de planificar. |
| C-008 · Media · B-05 | [`instructions.go:64`](../../pkg/installer/instructions.go#L64), [`uninstall.go:502`](../../pkg/installer/uninstall.go#L502). Ampliar el smoke de migración para detectar también las variantes sin marcas. |

Se mantienen fuera del recuento los problemas anteriores de `/plan` y de `deps-update`, que no se adjudicaron de nuevo en esta ronda. La aceptación del perfil híbrido actual y la migración de una variante histórica aislada no cubren los casos mixtos descritos aquí.
