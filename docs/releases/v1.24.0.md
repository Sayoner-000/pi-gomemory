# v1.24.0: codemode híbrido por defecto

`install` y `update` vuelven a dejar Pi en modo codemode híbrido (HCD-071). Es el valor que tenía v1.15.0 y que v1.15.4 cambió a directo. Lo recuperamos tras medirlo en una instalación real: con todas las tools MCP directas el modelo recibía unas 80 en cada turno; con el híbrido recibe 27.

## Qué cambia

### Híbrido por defecto
En modo híbrido, Pi declara al modelo solo las tools que usa a diario:

- **gomemory:** `get_context`, `get_plan_context`, `search_memories`, `get_memory`, `save_memory`, `start_session`, `save_session_summary`, `end_session`, `search_code`, `get_symbol`, `octopus_route_task` y `judge_memories`.
- **codebase-memory:** `search_graph`, `trace_path`, `get_code_snippet` y `check_index_coverage`.
- **codegraph:** `codegraph_explore`, siempre directa.

El resto (`review_*`, `pack_*`, `socratica_flow`, `query_graph`, `manage_adr`…) sigue disponible desde la tool `codemode` con `tools.<nombre>(args)`. Desde ahí también se pueden lanzar varias consultas en paralelo y filtrar salidas grandes antes de que entren al contexto.

Al instalar, pi-gomemory añade `+codemode` a `defaultTools` y anota en `~/.pi-gomemory/codemode.json` que lo añadió él, para retirarlo al desinstalar. Si `+codemode` ya estaba, no se lo atribuye.

### Quien prefiera el modo directo
```bash
pi-gomemory-setup codemode off
```
La elección se guarda y `install` y `update` la respetan. `codemode on` vuelve al híbrido.

### Tools que no ve el modelo
Algunas skills, como `socratica`, nombran tools que en modo híbrido no están declaradas. El protocolo que inyecta `gomemory-context.ts` en cada sesión pide ahora buscarlas con `searchTools` desde `codemode` antes de darlas por inexistentes y pasar a un flujo solo en texto.

### Lo que no cambia
- La lista de tools directas es la misma que en versiones anteriores, así que los `mcp.json` ya escritos se siguen reconociendo como propios.
- El subcomando `mcp` conserva el modo activo.
- El modo lite se combina con el híbrido igual que antes: gomemory híbrido y sin servidores de grafo.

## Actualización

```bash
pi-gomemory-setup update
pi-gomemory-setup codemode status
pi-gomemory-setup doctor
```

Si no habías elegido modo, `codemode status` debería responder `on`. Abre una sesión nueva de Pi o ejecuta `/reload` para que el modelo reciba la lista nueva.
