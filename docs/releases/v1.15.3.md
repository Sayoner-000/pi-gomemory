# v1.15.3 — Regresión de Antigravity y mitigación local documentada

## Alcance

Esta versión publica la referencia opt-in y las pruebas de regresión de la mitigación validada en HCD-040, junto con su diagnóstico y límites. **El guard no está embebido ni se instala por defecto: actualizar el binario no activa la mitigación.** No cambian los pins (`pi-antigravity@0.14.0`, `pi-cc-extensions@1.0.21`), las credenciales ni el hardening.

## Cambios

- Referencia en `tests/antigravity-prompt-guard/guard.mjs` y 22 pruebas offline, ejecutadas también por `TestHCD040PromptGuardRegression` desde la suite de Go. Node.js debe estar en el PATH; su ausencia hace fallar el test.
- [Diagnóstico de Antigravity](../antigravity.md): comparación controlada A/B/A con la misma credencial, riesgo de prioridad, activación manual y desactivación.
- README, badge, guías vigentes, problemas conocidos e índices actualizados. `install.sh` y `scripts/build-release.sh` usan v1.15.3 por defecto. Las notas y auditorías históricas se conservan.
- [HCD-040](../../hcd/HCD-040-subir-los-pins-a-pi-antigravity-0-14-0-y.md) cerrada con aprobación después de completar la validación de la instalación real. El rojo/verde reconstruido se identifica como evidencia nueva.

## Qué se validó y qué no

OAuth y la consulta de cuota funcionaban, pero la petición de generación original devolvía HTTP 429. Manteniendo la credencial y los demás parámetros, se obtuvo 429 con las instrucciones originales en `systemInstruction`, 200 al trasladar el mismo texto al primer turno de usuario y 429 al restaurar la petición original. Se recuperaron Hydrogen, Sonnet y un ciclo de herramientas; la persona confirmó el panel y las cuotas.

La mitigación conserva el texto, pero **reduce la prioridad de las instrucciones**. No garantiza seguridad equivalente frente a inyección de instrucciones ni resuelve necesariamente otros HTTP 429. Sigue siendo una decisión local explícita, no una corrección automática del instalador ni una nueva auditoría ACR/ADM independiente. Consulta los [problemas conocidos](../known-issues.md).

## Actualización

```bash
pi-gomemory-setup update
pi-gomemory-setup version
```

La versión debe indicar `v1.15.3`. Ejecuta `/reload` en Pi para recargar las extensiones actualizadas. Si necesitas el guard, sigue por separado la [activación manual y reversible](../antigravity.md#activación-manual-y-reversible); no borres credenciales ni desactives protecciones para diagnosticarlo.

## Validación de la entrega

```bash
go build ./...
go vet ./...
go vet -tags pins ./...
go test -race ./... -count=1
node --test tests/antigravity-prompt-guard/guard.test.mjs
go test -tags pins -count=1 -v ./pkg/installer -run '^TestPinsCheck$'
bash scripts/build-release.sh v1.15.3
```

El script de distribución repite los controles de Go, comprueba los pins frente a npm y genera cuatro paquetes con `SHA256SUMS`. La comprobación de entrega verifica las sumas, plataforma y metadatos Git de cada binario, la versión del ejecutable nativo y las copias descargadas de los assets publicados.
