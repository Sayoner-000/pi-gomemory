# v1.13.3 — Timeout propio en las consultas de versiones y `-race` al empaquetar

Fecha: 2026-11-13.

## Cambios

- **Timeout propio en `httpJSON` ([HCD-033](../../hcd/HCD-033-timeout-propio-en-httpjson-y-race-al-emp.md), C-002):** la consulta de la última versión en npm usaba `http.DefaultClient` y solo el contexto del llamador limitaba la espera. Hoy el único llamador ya pasaba un plazo de 20 s, así que no podía colgarse, pero un llamador futuro sin plazo sí. El cliente aplica ahora su propio límite de 20 s.
- **`-race` al empaquetar ([HCD-033](../../hcd/HCD-033-timeout-propio-en-httpjson-y-race-al-emp.md), C-003):** `scripts/build-release.sh` ejecuta `go test -race ./...` antes de compilar, como el `Makefile` y las verificaciones de cada unidad.

Con esta versión quedan corregidos los cuatro hallazgos de la [auditoría ACR/ADM de v1.12.1](../audits/2026-11-13-acr-adm-v1.12.1.md). Para quien usa pi-gomemory no cambia nada visible.

## Verificación

- `TestHCD033HTTPJSONClientTimeout`, observado primero en rojo: el cliente tiene el timeout configurado y una conexión que no responde termina con error aunque el contexto no tenga plazo.
- `go vet ./...` y `go test -race ./...` en verde; los binarios de esta release se compilaron con el script ya corregido.
