# v1.15.4 — Modo MCP directo (`codemode off`) por defecto

## Qué cambia

Desde esta versión, `pi-gomemory-setup install` y `update` dejan los tres servidores MCP (`gomemory`, `codegraph` y `codebase-memory`) en exposición `direct` (`codemode off`) por defecto ([HCD-050](../../hcd/HCD-050-install-y-update-dejan-codemode-off-mcp.md)).

El perfil híbrido sigue disponible bajo demanda:

```bash
pi-gomemory-setup codemode on
pi-gomemory-setup codemode status
```

Esa elección se guarda en `~/.pi-gomemory/codemode.json` y se mantiene en futuras actualizaciones. Para volver al modo directo basta con ejecutar `pi-gomemory-setup codemode off`.

## Migración desde v1.15.0 – v1.15.3

- Si nunca fijaste una preferencia manual con `codemode on`, al actualizar `install` retira el `+codemode` que había añadido la versión anterior (siempre que el destino real de `settings.json` coincida con el registro de propiedad) y deja los tres servidores en `direct`. Todo ocurre bajo rollback atómico para evitar estados parciales.
- Si activaste `codemode on` explícitamente, la actualización conserva tu configuración híbrida.
- Si añadiste `+codemode` por tu cuenta en `settings.json` o el enlace simbólico cambió de destino, `install` no toca `defaultTools` y deja únicamente los tres servidores MCP en `direct`.

## Actualización

```bash
pi-gomemory-setup update
pi-gomemory-setup version
pi-gomemory-setup codemode status
```

`version` debe devolver `v1.15.4` y `codemode status` debe indicar `codemode: off` (salvo que tengas `codemode on` guardado). Abre una sesión nueva o ejecuta `/reload` en Pi.
