# v1.24.1: skills HCD embebidas sin revalidaciones innecesarias

Las skills `hcd-implement` y `hcd-verify` iban embebidas en el binario de `pi-gomemory` con las instrucciones anteriores, por lo que actualizar `mem` no bastaba para que Pi aplicara las reglas de verificación introducidas en `HCD-060` (HCD-072). Esta entrega sincroniza ambas copias embebidas y mantiene intactas las personalizaciones locales al reinstalar.

## Qué cambia

### Skills `hcd-implement` y `hcd-verify`
- Durante la implementación se comprueba la tarea en curso mediante `mem hcd verify`, sin recorrer tareas anteriores caducadas después de cada edición.
- Se evita ejecutar la misma prueba fuera y dentro del motor (`verify` ejecuta y registra en una sola llamada, ya sea por CLI o por MCP).
- La evidencia caducada se conserva como registro histórico y se revalida antes del cierre, cuando el código está estable.
- `hcd-verify` permite agrupar tareas (`--task 2,3`) únicamente cuando el comando las prueba todas, mantiene una verificación por llamada Bash y evita repetir `mem hcd show` justo después de `verify` si no hubo cambios ni interrupciones.

### Pruebas y sincronización
`TestHCD072EmbeddedScheduling` verifica que `SyncSkillRepo` instala las reglas actualizadas en `~/.pi-gomemory/skills` y respeta cualquier edición previa que el usuario haya hecho en esas skills.

## Actualización

```bash
pi-gomemory-setup update
pi-gomemory-setup skills-sync
```

En Pi, abre una sesión nueva o ejecuta `/reload` si tienes skills cargadas en la sesión actual.
