# v1.23.0: atajo para el modo plan y glifos de /tasks más legibles

Esta versión añade `Alt+P` para entrar y salir del modo plan, muestra su estado en la cabecera de Pi, cambia dos glifos de `/tasks` que se veían mal en varias fuentes y corrige la versión que enseñaba la cabecera después de actualizar.

## Novedades

### Modo plan desde el teclado (HCD-067)

`Alt+P` activa o desactiva el modo plan. Hace lo mismo que `/plan on` y `/plan off`: no envía ningún mensaje ni inicia un turno.

En macOS, Option+P solo llega como `Alt+P` si la terminal trata Option como Alt. Cuando no es así, el editor recibe `π`. Para esos casos queda `Ctrl+Alt+P`, que funciona igual. En Windows y WSL solo se registra `Ctrl+Alt+P`, porque Pi usa allí `Alt+P` para volver al modelo anterior.

Shift+Tab no se usa porque Pi lo reserva para el nivel de thinking, y Ctrl+Tab no sirve porque la mayoría de terminales lo envían igual que Tab.

### Estado del modo plan en la cabecera (HCD-067)

Debajo del lema, la cabecera muestra una de estas dos líneas:

- `◆ MODO PLAN ON · Alt+P`, en ámbar (`#f4c66b`, el color `warning` del tema gomemory);
- `○ plan off · Alt+P`, atenuada.

La línea cambia en cuanto se usa el atajo o `/plan`, sin reiniciar Pi. Con `NO_COLOR` se dibuja sin colores. El estado se comparte entre `gomemory-plan.ts` y `gomemory-banner.ts` a través de `Symbol.for("pi-gomemory.plan")`.

La etiqueta `PLAN` del pie sigue ahí. Si usas pi-cc-extensions, el pie la pinta con el color de sus chips, así que el aviso en ámbar solo aparece en la cabecera.

## Cambios

### Glifos de /tasks (HCD-068)

La barra de progreso usaba `▰▱`. Muchas fuentes monoespaciadas no traen esos caracteres y la terminal los sustituía por los de otra fuente, con huecos entre celdas. Ahora es una línea de dibujo de cajas:

```
HCD-068 · evolution · paso implement · ━━━───────  1/4 · 25 %
```

La tarea caducada (estuvo verificada, pero el código cambió) pasa de `◍` a `↻` en ámbar. El resto de estados no cambia: `○` pendiente, `●`/`○` parpadeando en curso, `●` verificada y `✗` fallida.

## Correcciones

- La cabecera mostraba la versión anterior de gomemory y de pi-gomemory si aceptabas la actualización al abrir `pi-gomemory`. El launcher exportaba `GOMEMORY_INSTALLED_VERSION` y `PI_GOMEMORY_RUNNING_VERSION` antes de `deps-update`. Ahora las exporta después. El launcher se regenera al instalar o actualizar.

## Actualización

```bash
pi-gomemory-setup update
pi-gomemory-setup version
```

Comprueba que el resultado sea `v1.23.0`. Ejecuta `/reload` en cada sesión abierta de Pi o inicia sesiones nuevas.
