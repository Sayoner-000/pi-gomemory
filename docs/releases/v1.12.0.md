# v1.12.0 — Cuota de OpenAI Codex

Fecha: 2026-11-12.

## Cambios

- El panel `/sidebar` añade «▼ Codex Quota» para el proveedor `openai-codex`: porcentaje restante, barra y reinicio de las ventanas primaria y secundaria, habitualmente cinco horas y una semana.
- `pi-gomemory-setup codex-usage` devuelve el plan y las ventanas en JSON; `percent` representa porcentaje usado, no restante.
- La consulta usa la sesión OAuth de Pi y, si existe, su identificador de cuenta. No modifica ni renueva credenciales. Los errores HTTP, cuerpos de más de 1 MiB y respuestas sin ventanas no se presentan como cuota válida.

El refresco ocurre al abrir el panel, mediante eventos de sesión/modelo/respuesta y con un heartbeat de 30 segundos. Una guarda impide consultas simultáneas, pero los eventos forzados pueden generar más de una consulta por intervalo.

## Actualizar

```sh
pi-gomemory-setup update
pi-gomemory-setup version
```

Después, ejecuta `/reload` en Pi. Para usar la cuota, inicia sesión en Pi con el proveedor Codex mediante `/login` y selecciónalo como proveedor activo. La aplicación Codex por sí sola no sustituye esa sesión.

Antes de reinstalar, consulta [los problemas conocidos](../known-issues.md), en particular permisos de configuración y archivos añadidos a skills legacy.
