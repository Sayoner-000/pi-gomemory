# v1.12.1 — Cierre de HCD-027 y modo watch sin bucle

Fecha: 2026-11-13.

## Cambios

- **Permisos JSON (C-002):** al reescribir `mcp.json` y el resto de JSON gestionados se conserva el modo existente; los archivos nuevos se crean con `0600`. Si la escritura falla, el original queda intacto y no quedan temporales.
- **Skills legacy (C-001):** solo se retiran copias gestionadas intactas que contienen únicamente `SKILL.md` y su marca. Los archivos añadidos por la persona se conservan.
- **Ejecutor TDD (C-003, C-005):** timeout y aborto son causas explícitas no exitosas. El grupo de procesos del ejecutor se termina con SIGTERM y después SIGKILL, y las pruebas Go pendientes se cierran como fallidas con diagnóstico.
- **Playwright (C-004, C-006):** cada prueba se identifica por proyecto y ubicación, y su estado final sale del informe JSON oficial. Una salida parcial no aprueba pruebas. Las recuperadas en un reintento se cuentan como `flaky`, aparte, y un fallo definitivo prevalece.
- **`/tdd watch`:** ya no se ejecuta en cada turno ni bloquea al agente. Corre una vez cuando Pi termina el prompt (`agent_settled`), solo si hubo `edit`, `write` o `bash`, y no repite si el agente ya ejecutó `run_test_suite all`.
- **Integración Playwright opcional:** `TestHCD027PlaywrightIntegration` se omite si falta `PLAYWRIGHT_TEST_CLI`. Con la variable definida exige un ejecutor real accesible.

## Verificación

- Matriz por hallazgo e informes de dos revisores independientes: [verificación HCD-027](../audits/2026-11-12-hcd027-verification.md).
- `go test -race ./...`, `go vet ./...` y la integración real con Playwright `1.61.0-alpha` en verde.
- Modo watch probado en Pi 1.5.2 real: un prompt con 9 turnos y un `edit` produce una sola ejecución tras `agent_settled`; un prompt de solo lectura no produce ninguna.

## Actualizar

```sh
pi-gomemory-setup update
pi-gomemory-setup version
```

Después, ejecuta `/reload` en Pi para cargar la extensión TDD actualizada.
