# Notas de v1.31.0

Fecha: 2026-11-26

Esta versión quita el inspector `/tdd` y la integración con Antigravity (HCD-085).

`/tdd` no cubría lo que hacía falta, y el progreso de las tareas HCD ya se ve en `/tasks`. La integración con Antigravity consultaba `retrieveUserQuotaSummary`, una API interna de Google, con el token OAuth de tu cuenta y un User-Agent copiado del cliente oficial. Google bloquea o marca las cuentas que usan su API desde clientes no oficiales, y el sidebar repetía esa consulta cada 30 segundos.

## Qué desaparece

- `/tdd`, su panel y la tool `run_test_suite`. `/min` queda como atajo de `/sidebar min`.
- El plugin `pi-antigravity`: ni se instala ni se fija, y `doctor`, `deps-status`, `components` y `pins-validate` dejan de comprobarlo.
- La sección «Google AI Pro Quota» de `/sidebar` y los comandos `pi-gomemory-setup usage`, `quota` y `pi-gomemory usage`, que ahora responden «Comando desconocido».
- `antigravity-prompt-guard.js`, sus pruebas offline y `scripts/antigravity-pin-check.sh`.

Si tu modelo activo es de Antigravity, el sidebar lo muestra como proveedor genérico, sin hacer ninguna petición.

## Qué pasa al actualizar

El paso `[4/9]` de `install` ahora retira la integración:

- quita de `settings.json` las entradas `npm:pi-antigravity@0.12.0`, `@0.14.0` y `@0.15.0`, que son las que escribió pi-gomemory, y llama a `pi remove` con cada una;
- conserva con un aviso una entrada de `pi-antigravity` con otra versión, porque la añadiste tú;
- no toca `~/.pi/agent/antigravity-accounts.json`, que es tu sesión de Google, y avisa si existe.

Después de instalar las extensiones, `install` borra `gomemory-tdd.ts` y `antigravity-prompt-guard.js` de `~/.pi/agent/extensions` si su SHA256 coincide con el del manifiesto anterior. Si los editaste, o el manifiesto no los registra, se quedan y verás un aviso. `uninstall` aplica la misma regla, y `uninstall --packages` sigue reconociendo los pins antiguos de `pi-antigravity`.

```bash
pi-gomemory-setup update
```

Luego ejecuta `/reload` en Pi o abre una sesión nueva.
