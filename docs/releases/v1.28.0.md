# Notas de v1.28.0

Fecha: 2026-11-24

## Resumen

Retira codebase-memory-mcp. CodeGraph queda como único grafo externo de pi-gomemory.

## Cambios

- El catálogo de componentes (`pkg/installer/components.go`) ya no incluye `codebase-memory-mcp`: `install`, `sync`, `deps-*` y `doctor` dejan de instalarlo, actualizarlo y comprobarlo. Se borran `pkg/installer/tools_cbm.go` y la skill embebida `codebase-memory`, así que quedan 20.
- `mcp.json` registra solo `gomemory` y `codegraph`. `install`, `update`, `mcp` y `codemode` retiran la entrada heredada `codebase-memory` si coincide con una de las que escribía pi-gomemory, y conservan una definición personalizada.
- `deps-install` explica que codebase-memory-mcp se retiró, indica cómo actualizar el resto de herramientas y sale con 2.
- `/plan` pierde las reglas específicas de las tools `mcp__codebase_memory__*`.

## Para quien actualiza

Si tienes `codebase-memory-mcp` instalado, pi-gomemory no lo desinstala. Si lo registraste tú en `mcp.json`, la entrada se queda como está.
