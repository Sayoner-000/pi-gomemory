# v1.13.8 — `/tdd` con salida acotada y cuotas vacías rechazadas

Fecha: 2026-11-17.

## Cambios

Cierra los dos hallazgos de severidad media de la [auditoría defensiva del 2026-11-17](../audits/2026-11-17-defensive-qa.md) sobre v1.13.7 ([HCD-038](../../hcd/HCD-038-cerrar-h-01-y-h-02-de-la-adm-2026-11-17.md)).

### H-01: `/tdd` ya no acumula sin límite la salida de un proceso

`streamLines` guardaba como mucho 40 líneas, pero no limitaba su tamaño, y el texto pendiente de salto de línea crecía sin cota. Una suite que escribía 8 MiB en una sola línea los dejaba enteros en la memoria de Pi y en el diagnóstico.

- **Línea excesiva:** una línea de más de 64 Ki caracteres termina el proceso (SIGTERM y, si no responde, SIGKILL al grupo) y la ejecución falla con código 1 y el aviso «Salida rechazada: una línea excede el límite de 64 Ki caracteres». No se recorta para seguir, porque un resultado leído a medias podría salir en verde.
- **Diagnóstico acotado:** se guardan las últimas 40 líneas, cada una recortada a 1 Ki caracteres, con un total de 64 KiB contados en bytes UTF-8. El parser de cada suite sigue recibiendo las líneas completas.
- **Unidad HCD en el panel:** el check «Unidad HCD activa» leía el JSON de `mem hcd show --json` del diagnóstico. Con el recorte, esa línea de más de 1 Ki habría quedado partida y el panel habría perdido la unidad, así que ahora el check lee las líneas completas.

### H-02: la cuota de Antigravity no da por buena una respuesta vacía

Go acepta `null` y `{}` como JSON válido, así que una respuesta 200 sin cuotas pasaba por éxito: `usage` mostraba solo la cabecera, el panel lateral se quedaba en «Cargando cuota...» y el segundo endpoint nunca se consultaba.

- **Validación:** `usage` y `usage --json` exigen al menos un límite y porcentajes entre 0 y 100. Si la respuesta no cumple, prueban el endpoint siguiente; si ninguno responde con cuotas, terminan con código 1 y el panel lateral muestra el error.
- **Plan no informado:** si Google envía cuotas pero no el nombre del plan, la primera línea dice «Plan no informado». Antes se suponía «Google AI Pro (g1-pro-tier)».

## Actualizar

```sh
pi-gomemory-setup update
pi-gomemory-setup version
```

Después ejecuta `/reload` en Pi para cargar la extensión `/tdd` actualizada.

## Límites

- La validación de cuotas se probó con un servidor local. La consulta real contra Antigravity no formó parte de las pruebas.
- Un `remainingFraction` que falta en la respuesta se sigue leyendo como 0; distinguirlo de un cero real queda fuera de esta release.
- `pi-antigravity` y `pi-cc-extensions` siguen fijados en 0.12.0 y 1.0.16, aunque npm ya publica 0.14.0 y 1.0.20. Actualizarlos irá en una release aparte.
