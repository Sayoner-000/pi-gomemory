# v1.23.2: avisos de codemode a medias y de tools duplicadas

Versión de mantenimiento. No cambia el modo por defecto ni escribe configuración nueva. Añade avisos para dos situaciones que hacían que Pi cargara más tools de las necesarias sin que nada lo indicara (HCD-070).

## Qué cambia

### Codemode a medias
Si `settings.json` tenía `+codemode` (puesto a mano o por otra herramienta) y los servidores MCP seguían en directo, `install` y `update` lo dejaban así sin decir nada. Pi cargaba entonces todas las tools MCP directas y además `codemode`.

Ahora `install`, `update`, `doctor` y `codemode status` marcan ese estado como `parcial` y dicen cómo salir:

```bash
pi-gomemory-setup codemode on    # híbrido: tools de protocolo directas, el resto por codemode
pi-gomemory-setup codemode off   # directo: retira +codemode
```

El modo por defecto sigue siendo directo, como desde v1.15.4.

### Tools de codebase-memory duplicadas
`codebase-memory-mcp install` puede dejar una extensión para Pi, `~/.pi/agent/extensions/cbmem.ts`, que registra sus 17 tools sin prefijo. Como pi-gomemory registra también el servidor MCP `codebase-memory`, Pi veía cada tool dos veces (`search_graph` y `mcp__codebase_memory__search_graph`). Las de la extensión, además, no respetan el modo híbrido.

`install`, `update` y `doctor` detectan la extensión por su cabecera y muestran su ruta. No la borran porque no es de pi-gomemory. Para quitarla:

```bash
rm ~/.pi/agent/extensions/cbmem.ts
```

Si vuelves a instalar codebase-memory-mcp, pásale `--clients` con tus agentes y sin `pi`. No uses `codebase-memory-mcp uninstall` para esto: en la versión 0.12.1 no admite `--clients` y quita la integración de todos los agentes.

### `doctor`
Dos comprobaciones nuevas: «Modo codemode» (directo, híbrido o parcial) y «Tools de codebase-memory» (con o sin extensiones que dupliquen el servidor).

## Actualización

```bash
pi-gomemory-setup update
pi-gomemory-setup version
pi-gomemory-setup doctor
```

Comprueba que la versión sea `v1.23.2` y revisa las dos líneas nuevas de `doctor`. Si alguna sale con `⚠`, sigue el comando que indica y abre una sesión nueva de Pi o ejecuta `/reload`.
