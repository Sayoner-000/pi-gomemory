# v1.15.0 — contexto por sesión y codemode por defecto

Fecha: 2026-11-17.

## Cambios

Pi carga las reglas y la memoria del proyecto con `mem context` al iniciar cada sesión. La extensión `gomemory-context.ts` reutiliza el resultado durante esa sesión y lo añade como sección del prompt. La consulta espera hasta tres segundos y conserva hasta 24 576 bytes de texto UTF-8. Si falla o llega vacía, muestra una advertencia y mantiene solo el protocolo específico de Pi.

`install` y `update` activan codemode híbrido por defecto. Para seguir usando herramientas MCP directas:

```bash
pi-gomemory-setup codemode off
```

La elección queda en `~/.pi-gomemory/codemode.json` y se respeta en futuras instalaciones. `codemode on` vuelve a activarlo y `codemode status` muestra los marcadores de configuración. Las herramientas de memoria y consulta frecuente siguen directas; las restantes se llaman desde codemode. CodeGraph permanece directo.

`/plan` añade su método en otra sección y ya no reemplaza el prompt completo.

## Migración y desinstalación

La instalación deja de escribir el protocolo en `AGENTS.md` y retira las variantes históricas reconocidas, con o sin marcadores. Conserva tu texto, permisos y enlaces. Si solo había protocolo, borra el archivo normal o vacía el destino enlazado. `doctor` avisa si queda un bloque antiguo.

`uninstall` reconoce los perfiles MCP directo e híbrido intactos. Retira `+codemode` solo cuando el registro de propiedad indica que lo añadió pi-gomemory; no elimina una activación que ya existía.

## Actualizar

```bash
pi-gomemory-setup update
pi-gomemory-setup version
pi-gomemory-setup codemode status
pi-gomemory-setup doctor
```

Abre una sesión nueva o ejecuta `/reload` para cargar las extensiones. Los pins no cambian: `pi-antigravity@0.14.0` y `pi-cc-extensions@1.0.21`.

## Validación y límites

La entrega exige `go test -race ./...`, `go vet` con y sin la etiqueta pins y la comprobación de los pins contra npm. Los paquetes incluyen binarios para macOS y Linux, en arm64 y amd64, con `SHA256SUMS`.

La auditoría independiente anterior terminó incompleta sobre un snapshot de desarrollo; no se declara una aprobación ACR global de esta release. Siguen abiertos los casos de configuración parcial, sondeos locales fallidos y activación de `/plan` durante una ejecución. Revisa [problemas conocidos](../known-issues.md) antes de automatizar estas operaciones.
