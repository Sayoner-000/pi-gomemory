# v1.16.0 — `/tdd` multi-lenguaje y escucha en `bash`, `/tasks` en vivo, modo `lite` y guard de Antigravity

## Qué cambia

### 1. `/tdd` multi-lenguaje y reflejo de tests en `bash` ([HCD-051](../../hcd/HCD-051-soporte-python-pytest-y-escucha-de-tests.md))
- `detectSuites()` en `extensions/gomemory-tdd.ts` detecta ahora:
  - **Python:** `.venv/bin/pytest`, `uv run pytest` o `pytest`, además de `ruff` y `mypy` cuando están configurados.
  - **PHP:** `vendor/bin/phpunit`, `composer test` o `phpunit`, más `php -l`.
  - **Java:** `./mvnw`/`mvn test` y `./gradlew`/`gradle test`.
  - **JavaScript / HTML / CSS:** `npm test` o `vitest.config.*`, más `htmlhint`, `stylelint` y `eslint` si existen sus configuraciones.
- Añadidos parsers dedicados (`pytestParser`, `vitestParser`, `phpunitParser`, `javaTestParser`).
- Nuevo listener `tool_result` en `extensions/gomemory-tdd.ts` para reflejar en `/tdd` los tests que el agente ejecute directamente vía `bash` (`pytest`, `vitest`, `npm test`, `go test`, `phpunit`, `mvn`/`gradle test`, `playwright`, `mem hcd verify`).

### 2. Refresco en vivo de `/tasks` y guardrail de *steering* ([HCD-051](../../hcd/HCD-051-soporte-python-pytest-y-escucha-de-tests.md))
- `extensions/gomemory-tasks.ts` hace polling periódico (1.5 s) mientras una llamada `bash` con `mem hcd` está en curso (`tool_execution_start` → `tool_execution_end`).
- Bloqueo en `tool_call` (`isBundledHcdVerifyCommand`) si una llamada `bash` agrupa múltiples `mem hcd verify` o los envuelve en funciones/bucles, permitiendo que Pi entregue *steering* entre verificaciones.

### 3. Modo liviano (`lite on|off`) para contención de RAM ([HCD-051](../../hcd/HCD-051-soporte-python-pytest-y-escucha-de-tests.md))
```bash
pi-gomemory-setup lite on      # Deja solo gomemory en mcp.json (sin codegraph ni codebase-memory)
pi-gomemory-setup lite off     # Restaura gomemory, codegraph y codebase-memory
pi-gomemory-setup lite status
```

### 4. Workaround temporal de Antigravity embebido
- `extensions/antigravity-prompt-guard.js` se instala ahora con el resto de extensiones mientras upstream resuelve [pi-antigravity#152](https://github.com/Rahularya01/pi-antigravity/issues/152).
- Reversible por proceso con `ANTIGRAVITY_PROMPT_GUARD=off`.

## Actualización

```bash
pi-gomemory-setup update
pi-gomemory-setup version
```

`version` debe devolver `v1.16.0`. Abre una sesión nueva o ejecuta `/reload` en Pi.
