# v1.19.2 — Correcciones de la auditoría defensiva del 2026-11-20

Versión de mantenimiento con los dos hallazgos de la auditoría defensiva sobre v1.19.1. No cambia comandos ni configuración.

## Qué cambia

- **Final de un Bash truncado o con error en `/tdd`.** Pi añade al resultado final de Bash un aviso cuando trunca la salida (`[Showing lines a-b of N. Full output: …]`) y el estado cuando el comando falla (`Command exited with code N`). La reconciliación de v1.19.1 contaba esas líneas como salida y se desplazaba, así que un test que fallaba al final de una salida larga podía quedar sin resultado. Ahora se descartan antes de reconciliar.
- **Binario temporal de `install.sh`.** El script copia el binario a `pi-gomemory-setup.tmp.<pid>` antes de moverlo a su sitio. Si fallaba la copia, el cambio de permisos o el movimiento, ese temporal se quedaba en el directorio de instalación. Ahora se borra al salir.

## Actualización

```bash
pi-gomemory-setup update
pi-gomemory-setup version
```

Comprueba que el resultado sea `v1.19.2`. Ejecuta `/reload` en Pi o abre una sesión nueva.
